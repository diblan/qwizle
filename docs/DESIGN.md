# Design Direction

Qwizle should feel like a focused daily learning routine. The interface should be minimal, modern, and clean, with enough game-like energy to make returning feel natural without making the app feel childish.

The current visual identity is:

- Dark.
- Centered.
- Minimal.
- Game-like but not childish.
- Inspired by Loldle-style daily game layouts.

Use this color scheme from `FRONTEND.md`:

- Primary: `#C4B5FD`.
- Dark background: `#0F172A`.
- Surface: `#1E293B`.
- Text: `#E5E7EB`.
- Muted text: `#9CA3AF`.
- Accent: `#A78BFA`.

Frontend implementation details belong in `FRONTEND.md`. In particular, Qwizle currently uses Angular with Bootstrap classes and light project SCSS. Do not introduce Spartan UI, Angular Material, or another component library unless explicitly requested.

Design work should favor familiar product patterns, accessible controls, clear labels, keyboard-friendly interactions, and compact flows that make practice feel easy to start.
