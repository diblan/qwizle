# Product Sense

When details are underspecified, choose the option that best supports learning retention, daily habit formation, and a clear challenge flow.

Prefer features that a learner can understand in the running app without explanation. A small improvement that makes the daily practice loop easier to start, answer, or complete is usually better than a broad feature that only adds management surface area.

Keep product decisions aligned with the current non-goals:

- Do not add detailed learner track record dashboards unless explicitly requested.
- Do not add weighted question reappearance logic unless explicitly requested.
- Do not invent advanced progression rules while the product is still establishing its basic challenge loop.

Good product increments are observable. A human should be able to start the app, follow a short path, and see what changed. If a change is internal, pair it with tests or a documented command that proves why it matters.

When in doubt, make the daily learning experience simpler: fewer decisions before practice, clearer feedback after answering, and less navigation between intent and recall.
