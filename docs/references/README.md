# External References

Use this directory only for stable external references that are useful to future agents and legally appropriate to check in.

Do not copy full external articles, Reddit threads, or copyrighted pages into the repository. Prefer short summaries, links, and notes about why the reference matters.

If an external source affects durable project direction, summarize the decision in a product spec, design doc, ExecPlan, or architecture note instead of making future agents depend on the external page.
